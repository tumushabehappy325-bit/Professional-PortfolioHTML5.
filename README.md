## Pages
- `index.html`: home, with an introduction and a page outline
- `about.html`: about me, timeline (ordered list) and glossary (description list)
- `gallery.html`: three figures with captions and a captioned video
- `data.html`: skills table with thead, tbody and tfoot
- `contact.html`: labelled contact form

## Folders
- `images/`: wireframes, sitemap and the video poster
- `videos/`: page tour (MP4) and its captions (VTT)
- `design/`: design document with sitemap and wireframes (PNG, PDF, SVG)

## Run it
Open `index.html` in any browser. The project uses semantic HTML5 with lightweight page-level CSS; there are no scripts or build steps.
